# E-Commerce Groceries – MERN Stack 🛒

A full-stack **Grocery E-Commerce Web Application** developed as part of a **MERN Stack Internship**.

## 🔧 Tech Stack
- MongoDB
- Express.js
- React.js (Vite)
- Node.js
- JWT Authentication

## ✨ Features
- User & Admin role-based authentication
- Admin Dashboard
  - Add, Edit & Delete products
  - View customer orders
- Product listing with search & filter
- Cart & Checkout flow
- Order management
- Responsive UI (Mobile Friendly)

## 🧑‍💼 Roles
- **User**: Browse products, add to cart, place orders
- **Admin**: Manage products and view all orders

## 📂 Project Structure

E-Commerce_Groceries/
├── frontend/ # React + Vite
├── backend/ # Node.js + Express
